# NEXABio logo

The project owner selected concept B: interwoven polymer loops, representing biomaterials and collaboration. The wordmark is **NEXABio**.

- `nexabio-logo-light-v1.png`: deep green and orange on white; used in the website header.
- `nexabio-logo-dark-v1.png`: white and orange on deep green; used in the footer and poster.
- `prompts.json`: the imagegen prompts used to prepare these versions from the selected concept.

The originals are PNG assets, 2172 × 724 pixels. Matching lossless WebP files carry the same pixels for website delivery. Their backgrounds are included in the artwork. Preserve their 3:1 aspect ratio and keep the surrounding clearspace. They are not vector files or an official UT Dallas/NSF seal.

Intended colors: deep green `#154F43`, burnt orange `#C7602C`, and white. Use the light version on white and the reversed version on deep green. Generated pixels can vary slightly from these reference colors.

The website and poster use these same source files. The poster logo is a replaceable image, while the surrounding text remains editable. After changing the logo, rebuild the poster and review its PDF before updating the website downloads.
